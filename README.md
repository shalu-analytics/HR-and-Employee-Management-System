# 📊 HR and Employee Management System

## 📝 Project Description
This repository contains a relational database model built from scratch using ** MySQL**. The project simulates a real-world management
system by structuring data across **5 interconnected tables**. It focuses on ensuring data integrity through preventing data redundancy 
via normalization, and writing structured queries to extract actionable business insights.

---

## 🛠️ Tech Stack & Skills
* **Database Management System:**  MySQL
* **SQL Concepts Applied:** DDL (Data Definition Language), DML (Data Manipulation Language), Joins, Aggregate Functions, Constraints
 Not Null, Data Normalization.

---

## 📐 Database Schema & Architecture
The database consists of **5 core tables** linked together through relationships:

* **t_employees** – Stores primary profile records and unique identities.
* **t_department** – Stores department names with primary and unique key.
* **t_dept_managers** – Manages hiring date.
* **t_dept_emp** –Manages hiring date. 
* **t_salries** – Employees salary records.

## 💡 Key Insights & Queries
* Workforce Density: Identified department strength and isolated business units holding over 20,000 staff members.
* Compensation Metrics: Calculated department-wise average salaries and tracked individual peak career earnings.
* Pay Equity & Demographics: Audited salary distributions across genders to check organizational pay parity.
* Hiring Growth Tracks: Evaluated workforce growth trends by mapping annual hiring patterns over time.
